# Subway Surfers AI Bot

[![Python 3.10](https://img.shields.io/badge/python-3.10-blue)](https://python.org)
[![TensorFlow 2.13](https://img.shields.io/badge/TensorFlow-2.13-orange)](https://tensorflow.org)

> **Статус:** завершенный исследовательский прототип.
> Цель - проверить, применим ли screenshot-based vision-подход для управления в динамичной игре, и оценить latency-бюджет.
> Отрицательный результат разобран.

## О проекте
Прототип агента для Subway Surfers на основе компьютерного зрения и глубокого обучения: 
захват кадра экрана -> предобработка -> инференс модели -> выбор действия -> отправка действия в эмулятор через ADB.

**Гипотеза**: цепочка «скриншот -> модель -> действие» успевает реагировать на события в игре с высокой динамикой. 
Гипотеза **не подтвердилась** в текущей реализации — причины и выводы описаны ниже.

## Архитектура pipeline
[Эмулятор] -> ADB screencap -> предобработка -> инференс TensorFlow-модели -> выбор действия -> ADB input -> [Эмулятор]


## Стек
- Python 3.10
- TensorFlow 2.13 (обучение и инференс)
- Компьютерное зрение: обработка кадров, кроп ROI, нормализация
- ADB - захват экрана и отправка действий в эмулятор
- Git / GitHub

## Структура проекта

- `src/` - исходный код (захват, препроцессинг, инференс, управление)
- `data/` - данные для обучения
- `models/` - сохранённые веса модели
- `config/` - конфигурации (параметры захвата, ROI, модель, пороги)

## Установка

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение с Python 3.10.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Установите ADB и настройте эмулятор Android с Subway Surfers.

## Использование

Запуск захвата и инференса:

```bash
python src/main.py --config config/default.yaml
```

## Выводы
- Гипотеза о применимости screenshot-based подхода «как есть»
не подтвердилась.
- Основное ограничение - end-to-end latency, а не качество модели.
- Для реального времени нужны: легкая модель, кроп только ROI, frame skipping, асинхронный захват и инференс, либо прямой доступ к состоянию игры/эмулятора.
- Проект закрыт как исследовательский прототип с отрицательным результатом.
